# Preferências do projeto

- A cada entrega com alterações no projeto, aumente a versão em `changelog.json` e registre as mudanças com a data local do usuário.
- Use incremento de patch por padrão (por exemplo, `0.8.1` → `0.8.2`), salvo solicitação de outro tipo de versão.
- Sincronize os valores de versão de fallback da tela inicial em `index.html` com `changelog.json`.
- Toda entrega com alterações deve incluir uma mensagem de commit em português na resposta final. Não crie commits nem faça push sem solicitação do usuário.
